# Πλάνο: Κάρτες βιβλίων Portify σε κάθε τάξη («Υπό κατασκευή»)

## Τι θα φτιαχτεί
Σε **κάθε σελίδα τάξης** (Α΄, Β΄, Γ΄ Γυμνασίου) θα προστεθεί μια νέα ενότητα με **κάρτες βιβλίων**:
- Κάθε κάρτα δείχνει το **εξώφυλλο (thumbnail)** και τον **τίτλο** του βιβλίου.
- Κλικ στην κάρτα → ανοίγει η αντίστοιχη σελίδα του βιβλίου στο **Portify** σε **νέα καρτέλα**.
- Πάνω/δίπλα στην ενότητα μπαίνει ταμπέλα **«Υπό κατασκευή»**.

Τα υπάρχοντα μαθήματα της τάξης παραμένουν ως έχουν· η ενότητα βιβλίων προστίθεται ξεχωριστά (πάνω από τα μαθήματα).

## Ποια βιβλία
Θα αντληθούν τα βιβλία **Μαθηματικών Γυμνασίου** από το Portify (τίτλος, εξώφυλλο, link ανά βιβλίο), ένα σετ ανά τάξη:
- Α΄ Γυμνασίου → βιβλία Μαθηματικών Α΄ Γυμνασίου
- Β΄ Γυμνασίου → βιβλία Μαθηματικών Β΄ Γυμνασίου
- Γ΄ Γυμνασίου → βιβλία Μαθηματικών Γ΄ Γυμνασίου

Αν μια τάξη έχει περισσότερα από ένα σχετικά βιβλία στο Portify (π.χ. Βιβλίο Μαθητή + βιβλίο ασκήσεων/λύσεων), θα εμφανιστούν όλα ως ξεχωριστές κάρτες.

## Υποθέσεις (αν δεν συμφωνείς, πες μου)
1. Η ενότητα βιβλίων μπαίνει **πάνω** από τα υπάρχοντα μαθήματα σε κάθε τάξη, με τίτλο π.χ. «Βιβλία (Πολλαπλό βιβλίο)» και badge «Υπό κατασκευή».
2. Το κλικ ανοίγει το Portify σε **νέα καρτέλα**.
3. Οι κάρτες αυτές είναι **σύνδεσμοι προς τα έξω** (Portify) — ΔΕΝ ανοίγουν εσωτερικά μαθήματα μέσα στην εφαρμογή. (Διαφορετικές από την παλιά «αδρανή» λογική επιλογής βιβλίου που έδειχνε εσωτερικά μαθήματα.)
4. Θα καταχωρήσω εγώ τα βιβλία Μαθηματικών Γυμνασίου· θα παραμείνουν και διαχειρίσιμα από το Admin panel για μελλοντικές αλλαγές.

## Εκτός πλάνου (δεν γίνονται τώρα)
- Ενσωμάτωση/αντιγραφή περιεχομένου του Portify μέσα στην εφαρμογή (μόνο link προς τα έξω).
- Βιβλία άλλων μαθημάτων ή βαθμίδων (μόνο Μαθηματικά Γυμνασίου).
- Λειτουργικό «πολλαπλό βιβλίο» με εσωτερικά μαθήματα ανά βιβλίο (μένει σε αναμονή όπως ήταν).

## Σημείωση για GitHub
Το «Save to Github» ανεβάζει μόνο τον κώδικα. Τα βιβλία αποθηκεύονται στη βάση δεδομένων (MongoDB) — δεν μεταφέρονται μέσω GitHub. Θα καταχωρηθούν απευθείας στο περιβάλλον της εφαρμογής.
